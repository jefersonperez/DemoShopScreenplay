
#  Proyecto Web (Selenium / Serenity)


 Web Automation - Serenity BDD (Screenplay)

Proyecto de automatización de pruebas funcionales para aplicaciones web utilizando el patrón **Screenplay** con **Serenity BDD**, enfocado en escalabilidad, reutilización y buenas prácticas.



##  Tecnologías utilizadas

- Java
- Selenium WebDriver
- Serenity BDD
- Cucumber
- Screenplay Pattern
- Maven


##  Patrón de diseño

Se utiliza el patrón **Screenplay**, que permite:

- Alta reutilización de código
- Separación de responsabilidades
- Escenarios más legibles

Para la ejecuciòn del proyecto se puede ir a la clase runner y cambiar la etiqueta por la que se necesite

para crear un nuevo usuario en el feature demoWebShop.feature en registro se debe cambiar el correo en ambos flujos
el de registrar y el de comprar

para ejecutar la automatizaciòn se debe tener previamente configurada la maquina con java, mvn, intelliji
se necesita java 11 para que no haya complicaciones al ejecutar.
